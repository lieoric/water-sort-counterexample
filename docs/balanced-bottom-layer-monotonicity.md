# 平衡底层扩张单调性定理

## 摘要

本文证明 Water Sort 平衡实例的一种高度单调性。设一个实例有 `c` 种颜色、
`c` 根初始满栈、`k` 根初始空栈，所有栈容量为 `h`，且每种颜色恰好出现
`h` 次。在每根满栈底部增加一个单位，使新增的一层恰好包含每种颜色一次，
并把所有栈的容量增加到 `h+1`。若原实例无解，则扩张实例仍然无解。

等价地，若扩张实例可解，则删除新增底层后得到的原实例也可解。证明基于
Ito 等人的 top-border 可达性刻画，但高度单调性及其投影论证是新增结论。

## 1. 形式系统与“无解”的定义

### 1.1 栈与局面

固定有限颜色集合 `C`、容量 `h>=1` 和有限栈集合 `B`。一根栈是一个长度不
超过 `h` 的颜色序列，按从底到顶书写。全体可能的栈记为 `C^{<=h}`。

一个局面是映射

```text
S : B -> C^{<=h}.
```

形式上可以给栈编号；可解性不依赖编号，因此实现可以把栈排序以消除栈置换
对称性。空序列记为 `epsilon`。形如 `q^r` 的非空序列称为颜色 `q` 的单色
栈。当 `r=h` 时，它是满单色栈或完成栈。

### 1.2 合法 Water move

选择不同的源栈 `i` 和目标栈 `j`。设源栈可唯一写成

```text
S(i) = u q^r,
```

其中 `r>=1`，`q^r` 是源栈的最大顶部同色段：`u` 为空，或 `u` 的顶色不为
`q`。要求源栈不是已经锁定的满单色栈。

设目标栈为 `S(j)=v`。目标必须满足：

```text
|v| < h，且 v 为空或 v 的顶色为 q。
```

令

```text
d = min(r, h-|v|).
```

一次合法的强制批量移动把局面 `S` 变为 `S'`：

```text
S'(i) = u q^(r-d),
S'(j) = v q^d,
```

其他栈保持不变。这里不能自行选择较小的移动量；`d` 由顶部同色段和目标
剩余容量唯一决定。把一步移动关系记为 `S -> S'`，其自反传递闭包记为
`S ->* T`。

### 1.3 目标局面

局面 `T` 是目标局面，当且仅当每根栈都满足以下二者之一：

```text
T(b) = epsilon；
T(b) = q^h，其中 q 属于 C。
```

即每根栈要么为空，要么是满单色栈。部分填充的单色栈不是目标栈。

### 1.4 可解与无解

给定初始局面 `S_0`：

> **可解（YES）**：存在目标局面 `T`，使 `S_0 ->* T`。

形式化为

```text
YES(S_0)  <=>  exists T: Goal(T) and S_0 ->* T.
```

> **无解（NO）**：不存在任何从 `S_0` 出发能够到达的目标局面。

形式化为

```text
NO(S_0)  <=>  for all T, S_0 ->* T implies not Goal(T).
```

等价地，令 `Reach(S_0)` 为所有可达局面的集合，则

```text
NO(S_0)  <=>  Reach(S_0) intersect Goal = empty.
```

“无解”不等于“初始局面没有合法移动”。一个 NO 初始局面可以有很多合法
移动；它的含义是所有选择最终都无法到达目标。

### 1.5 物理死局：完全没有合法 Water move

令

```text
U(S) = {i : S(i) 非空，且 S(i) 不是锁定的满单色栈}
```

为可以充当源栈的集合。对非空栈 `w`，用 `top(w)` 表示其顶色。一个非目标
局面 `S` 是**物理死局**，当且仅当

```text
for every i in U(S), for every j != i:
    |S(j)| = h
    or
    (S(j) != epsilon and top(S(j)) != top(S(i))).
```

数学式写作

```text
S not in Goal，且
forall i in U(S), forall j != i,
|S(j)|=h or (S(j)!=epsilon and top(S(j))!=top(S(i))).
```

也就是说，每个可能的目标栈要么已经满了，要么非空且顶色与源栈不同。
不存在空的非满目标，也不存在顶色相同的非满目标，所以一步 Water move 都
无法执行。

### 1.6 边界死局：仍可倒水，但不能再消除颜色边界

完整 Water 状态中可能仍有一些不会消除原始边界的整理或来回移动。对可解性
而言，更关键的是 top-border 抽象中是否还能取得不可逆进展。

给定非零 top-border table `tau`，令

```text
A(tau) = 当前空栈及单色栈总数；
N_b(tau) = sum_q M_q^b(tau)，
```

其中 `N_b(tau)` 是消除活动源边界 `b` 所需的单色缓冲栈数。边界 `b` 可消除
当且仅当

```text
N_b(tau) <= A(tau).
```

因此 `tau` 是**边界死局**，当且仅当

```text
tau != 0，且
for every b with tau(b)>0:
    N_b(tau) > A(tau).
```

即

```text
tau != 0
and
forall b with tau(b)>0,
sum_q M_q^b(tau) > A(tau).                            (D)
```

在平衡模型中，每个 `M_q^b` 只能是 `0` 或 `1`，所以 `N_b` 就是消除边界
`b` 时存在正缓冲缺口的颜色种数。比如有两根可用单色缓冲栈，而对每个活动
源边界都有三种颜色需要缓冲，则

```text
A(tau)=2，且对所有 b 都有 N_b(tau)=3，
```

由条件 (D)，该状态是边界死局。

物理死局一定没有下一步真实移动；边界死局则可能还允许不消除边界的倒水，
但不存在任何能够降低 top-border table 的进展步骤。本文的单调性证明使用的
是第二种定义。

Top-border 图是有限有向无环图，因为每条边都严格消除一个原始颜色边界。
因此从初始 table `tau_0` 出发，每条最大边界消除路径都必然有限，并终止于
全零目标或某个非零边界死局。由此得到等价刻画：

```text
NO(tau_0)
<=> 0 不可从 tau_0 到达
<=> 每一条从 tau_0 出发的最大边界消除路径，都终止于非零边界死局。
```

量词“每一条”不可省略。一个 YES 实例也可能因为错误选择而到达某个局部
死局；只要还存在另一条路径到达 `0`，它仍然是 YES。只有所有分支都不能
到达 `0`，才称初始局面为 NO。

### 1.7 NO 证书

如果能够给出一个局面集合 `R`，满足：

1. `S_0` 属于 `R`；
2. `R` 不包含任何目标局面；
3. `R` 对合法移动封闭：若 `S` 属于 `R` 且 `S -> S'`，则 `S'` 也属于 `R`；

那么 `R` 就是严格的 NO 证书。因为从 `S_0` 出发永远无法离开 `R`，而 `R`
中没有目标。项目中的二进制证书在 top-border 抽象图上使用同样的“包含
初态、排除目标、对后继封闭”原则，并由独立验证器重新检查所有抽象转移。

### 1.8 实例级结论与参数级结论

`NO(S_0)` 描述一个具体初始局面。另定义

```text
E(c,h,k) = 存在一个 c 色、容量 h、k 个初始空栈的平衡 NO 实例。
```

所以 `E(c,h,k)` 是“存在至少一个 NO”，并不表示相同参数下的所有实例都
无解。本文首先证明具体实例的底层扩张保持 NO，再将其推出参数级单调性。

## 2. 平衡实例与底层扩张

令颜色集合为 `C`，其中 `|C|=c`。一个高度为 `h` 的平衡实例 `I` 包含：

- `c` 根初始满栈 `b_1,...,b_c`；
- `k` 根初始空栈；
- 每根栈容量为 `h`；
- 每种颜色恰好出现 `h` 次。

第 `i` 根满栈按从底到顶写作

```text
S_i = x_{i,1} x_{i,2} ... x_{i,h}.
```

选择颜色集合 `C` 的一个排列 `pi`，定义高度为 `H=h+1` 的扩张实例 `I+`：

```text
S_i+ = pi(i) x_{i,1} x_{i,2} ... x_{i,h}.
```

所有栈（包括初始空栈）的容量同时增加到 `h+1`。因为 `pi` 使用每种颜色
恰好一次，`I+` 中每种颜色恰好出现 `h+1` 次，所以 `I+` 仍是平衡实例。

## 3. 定理

> **平衡底层扩张单调性定理。**
> 对上述任意平衡实例 `I` 及任意颜色排列 `pi`，都有
>
> ```text
> I+ 可解  =>  I 可解。
> ```
>
> 等价地，
>
> ```text
> I 无解  =>  I+ 无解。
> ```

该结论与具体的 `c`、`h`、`k` 数值无关。

## 4. Top-border 判据

以下使用 Ito 等人的 top-border 刻画。对每根栈，颜色发生变化的位置称为
border；`0` 表示该栈已经没有颜色边界，即为单色栈。一个 top-border table
`tau` 记录每根栈当前尚未消除的最高原始边界。

对准备消除的源边界 `b` 和颜色 `q`，定义：

- `F_q(tau)`：当前所有最高边界上方，颜色 `q` 的单位总数；
- `G_q(tau)`：所有顶色为 `q` 的非单色栈，其边界上方可容纳的总量；
- `U_q^b(tau)`：从 `G_q` 中扣除源栈 `b` 自己的顶部容纳量；
- `Delta_q^b(tau)=F_q(tau)-U_q^b(tau)`：颜色 `q` 的缓冲缺口；
- `M_q^b(tau)`：容纳该缺口所需的单色栈数。

容量为 `h` 时，

```text
M_q^b(tau) = max(0, ceil(Delta_q^b(tau) / h)).
```

令 `A(tau)` 为当前空栈及单色栈的总数。源边界 `b` 可以消除，当且仅当

```text
sum_q M_q^b(tau) <= A(tau).
```

Ito 等人的 Theorem 3 与 Corollary 5 说明：初始实例可解，当且仅当存在一条
合法 top-border 路径把所有边界消除到 `0`。

## 5. 边界投影

在 `I+` 中，原来位于位置 `t` 的边界移动到位置 `t+1`。如果新增底色
`pi(i)` 与原底色 `x_{i,1}` 不同，还会在位置 `1` 产生一个新边界。

定义投影

```text
p(t) = max(t-1, 0).
```

因此：

- 原始边界 `t+1` 投影回原边界 `t`；
- 新底层边界 `1` 投影为 `0`；
- 完成状态 `0` 仍投影为 `0`。

假设 `I+` 可解，并取一条从其初始 top-border table 到全零 table 的合法路径。
对路径逐状态应用 `p`。消除新底层边界的步骤 `1 -> 0` 投影成停顿
`0 -> 0`，将这些停顿删除。其他步骤都对应原实例中的某个原始边界消除。

只需证明每个保留下来的投影步骤在原实例中仍然合法。

## 6. 状态分类

在扩张路径中准备消除一个原始边界时，把初始满栈分为三类：

1. **活动栈 A**：最高边界至少为 `2`，仍有原始边界；
2. **待处理栈 P**：最高边界为 `1`，原始边界已全部消除，但新底层边界仍在；
3. **完成栈 Z**：最高边界为 `0`，所有边界均已消除。

令

```text
r = |P|.
```

P 中的栈在扩张状态中尚不是单色栈；投影到原实例后，新底层不存在，而所有
原始边界已经消除，所以它变成单色栈。其他栈的单色状态不变。因此

```text
A = A+ + r,                                           (1)
```

其中 `A+` 是扩张状态的空栈/单色栈数，`A` 是投影状态的空栈/单色栈数。

## 7. 比较 F、G 与缓冲缺口

固定一个将要消除的原始源边界 `b`。该源栈属于活动栈 A；它的顶部段长度在
投影前后相同，因为

```text
(h+1) - (t+1) = h-t.
```

对每种颜色 `q`，定义：

```text
a_q = P 中顶色为 q 的栈数；
z_q = Z 中新增底层颜色为 q 的单位数。
```

显然

```text
sum_q a_q = r.                                        (2)
```

对于活动栈和待处理栈，新增底层仍位于当前最高边界下方，不计入 `F+`；只有
完成栈中的新增单位被计入。因此

```text
F_q+ = F_q + z_q.                                     (3)
```

活动栈在投影前后的 `G` 贡献相同。每根待处理栈在扩张状态中具有位置 `1`
的边界，并在该边界上方提供恰好 `h` 个顶色为原底色的宿主位置；投影后该栈
已经单色，不再贡献 `G`。因此

```text
G_q+ = G_q + h a_q.                                   (4)
```

源栈属于活动栈，其被扣除的顶部容量在两个实例中相同，所以

```text
U_q^{+,b} = U_q^b + h a_q.                            (5)
```

由 (3) 与 (5)：

```text
Delta_q^{+,b}
  = F_q+ - U_q^{+,b}
  = Delta_q^b + z_q - h a_q.                          (6)
```

## 8. 平衡性使缓冲需求成为 0/1 指示量

原实例中颜色 `q` 的总量为 `h`，所以 `F_q<=h`。又因为 `U_q^b>=0`，有

```text
Delta_q^b <= h.
```

故

```text
M_q^b = 1  当且仅当 Delta_q^b > 0；
M_q^b = 0  当且仅当 Delta_q^b <= 0.
```

扩张实例中每种颜色总量为 `h+1`，同理 `M_q^{+,b}` 也只能是 `0` 或 `1`。

如果某颜色在原实例中有正缺口，即 `Delta_q^b>0`，并且 `a_q=0`，由 (6)
可得

```text
Delta_q^{+,b} = Delta_q^b + z_q > 0.
```

因此，原实例中缺缓冲、但扩张实例中不缺缓冲的颜色，必定满足 `a_q>0`。
每个满足 `a_q>0` 的颜色至少占用一根待处理栈，而待处理栈总共只有 `r` 根。
由 (2) 得

```text
sum_q M_q^b <= sum_q M_q^{+,b} + r.                   (7)
```

## 9. 合法性保持

因为待投影的原始边界在扩张路径中合法，

```text
sum_q M_q^{+,b} <= A+.
```

结合 (7) 与 (1)：

```text
sum_q M_q^b
  <= sum_q M_q^{+,b} + r
  <= A+ + r
  = A.
```

这正是该边界在原实例中合法的条件。因此，扩张路径中每一次原始边界消除都
可以投影成原实例中的合法边界消除。

删除所有投影停顿后，得到一条从 `I` 的初始 top-border table 到全零 table
的合法路径。由 Ito 的 top-border 可达性定理，`I` 可解。

所以

```text
I+ 可解  =>  I 可解。
```

取逆否命题：

```text
I 无解  =>  I+ 无解。
```

证毕。

## 10. 完成栈锁定规则

Ito 的原始模型允许把一根满单色栈整体倒入空栈。平衡实例中，这种操作只会
交换一根满单色栈和一根空栈的物理身份。由于栈没有标签，可以删除该操作，
并在后续步骤中交换两根栈的名称。反复删除这种空操作，即可把任意解转换成
不再移动完成单色栈的解。

所以在这里使用“满单色栈完成并锁定”的规则不改变可解性，也不影响上述证明。

## 11. 推论

### 推论 1：任意高度扩张

逐层重复定理可得，对任意整数 `t>=0`：

```text
I_h 无解  =>  I_{h+t} 无解，
```

前提是每个新增横向底层都恰好使用每种颜色一次。

### 推论 2：无解存在性的高度单调性

令 `E(c,h,k)` 表示存在一个相应参数的平衡 NO 实例，则

```text
E(c,h,k) => E(c,h+1,k).
```

等价地，如果某高度不存在任何 NO，则所有更低高度也不存在 NO。

### 推论 3：无解存在性的颜色单调性

从任意平衡实例 `I` 出发，增加一种新颜色，并增加一根由该新颜色填满的完成
栈。新栈从初始时刻起已经锁定，既不能作为源栈，也因为已满而不能作为目标
栈。因此它不参与任何合法移动；删除该栈会把扩张实例的每条解投影成原实例
的一条解。取逆否命题可得

```text
E(c,h,k) => E(c+1,h,k).
```

即使采用允许移动完成栈的原始 Water 规则，把这根新栈整体倒入空栈也只会
交换完成栈与空栈的物理编号，所以结论不变。

结合高度单调性，对固定 `k`，存在 NO 的参数集合在 `(c,h)` 的坐标偏序下
向右、向上封闭。其补集，也就是所有实例均可解的参数集合，向左、向下封闭。

### 推论 4：一空栈的完整存在性分类

完整枚举得到：

| `(c,h,k)` | 精确对称类 | YES | NO |
|---|---:|---:|---:|
| `(2,3,1)` | 7 | 7 | 0 |
| `(3,2,1)` | 5 | 5 | 0 |
| `(2,4,1)` | 23 | 22 | 1 |
| `(3,3,1)` | 55 | 48 | 7 |
| `(4,2,1)` | 12 | 11 | 1 |

后三个参数点各保存了一个独立验证的 NO 证书。前两个安全点的向下闭包覆盖
所有非平凡安全候选，后三个无解点的向上闭包覆盖其余参数。因此

```text
E(c,h,1)
<=> c>=2，h>=2，且 c+h>=6。
```

这里仍然只断言相应参数下“至少存在一个 NO”，不表示该参数下所有实例都
无解。

### 推论 5：五色两空栈的完整高度分类

完全枚举已经证明 `c=5,k=2` 时所有 `h<=4` 的实例可解；四个高度 5 的
实例具有独立验证的 NO 证书。因此

```text
E(5,h,2) 当且仅当 h>=5.
```

此外，完整枚举证明 `(4,5,2)` 的 20,434,876 个精确对称类全部可解，而
`(5,4,2)` 也已经完整证明全部可解。因此 `(5,5,2)` 的 NO 见证没有任何
坐标逐项更小的 NO 参数点；`(5,5)` 是 `k=2` 无解存在区域的一个最小元。

## 12. 计算验证

形式证明之外，还进行了两类计算核验。

### 独立完整 Water BFS

使用不调用 top-border oracle 的完整状态 BFS，直接执行强制批量倒水和完成栈
锁定规则，检查了：

- 261 个由完整状态搜索确认的 NO 父实例；
- 它们的 5,825 个不同平衡底层扩张；
- 共访问 79,047 个真实 Water 状态。

没有出现一次 `NO -> YES`。

### 高度 5 证书实例

- 四个高度 5 的 NO 实例共产生 360 个不同的一层平衡扩张；
- 360 个扩张全部由精确 top-border 判定器确认为 NO；
- CI 固定检查其中一个高度 5 实例的全部 120 种底层排列；
- 当前完整 CTest 测试集全部通过。

计算结果不是一般性证明的替代品，但能够独立检查证明陈述、索引投影和实际
Water 移动规则之间是否存在小规模偏差。

## 13. 适用范围与未覆盖情形

定理要求：

1. 每种颜色的总量等于栈容量；
2. 初始满栈数等于颜色数；
3. 每次新增一格到每根初始满栈的底部；
4. 每个新增横向底层恰好包含每种颜色一次；
5. 所有栈容量同步增加一格。

本证明没有声称覆盖：

- 颜色总量不等于容量的非平衡实例；
- 只增加部分栈容量；
- 新增底层没有逐层保持颜色平衡的任意填充；
- “高度增加后所有实例都无解”。

定理证明的是无解实例的存在性可以向更高高度构造性传播，而不是更高高度的
每一个实例都无解。
