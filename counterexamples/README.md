# Verified counterexamples

This directory contains five pairwise inequivalent counterexamples found by
GitHub Actions run 31308013218. Equivalence here allows arbitrary renaming of
the five colors and arbitrary permutation of the five initially full columns.

Every instance has height 16, five colors, five full columns, and two empty
columns. Its matching `.wscert` is a transition-closed top-border invariant
that is checked independently by `water-verify`.

Columns in the text files are written bottom-to-top. See `index.tsv` for the
original hunt shard and basic exact-oracle statistics.
